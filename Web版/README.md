# 使用说明 · 边合区产业地图 Web 版

## 打开方式

**方式一（最简单）**：双击 `index.html`，浏览器直接打开。

**方式二（本地服务，推荐手机访问时用）**：
```
cd Web版
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123 ；手机访问用电脑局域网 IP
```

> 瓦片来自天地图（需联网）；底图用浏览器端 tk，
> 服务端校验浏览器 UA，正常浏览器访问无需任何配置。

## 操作对照（与 App 基本一致）

| 操作 | App | Web 版 |
|---|---|---|
| 缩放/平移 | 手势 | 滚轮/拖拽/双击 |
| 显示控制浮层 | 左下主按钮 | 右下 ☰ 按钮 |
| 版权信息页 | 点版本号 | **点**右下角 `Web v0.3.0` |
| 校准读数 | 长按指北针 | **长按**版本号 600ms |
| 看企业档案 | 点标签/圆点 | 点标签/圆点（三段式面板：简介内部滚动） |
| 闲置地块/厂房图层 | 浮层第 4/5 行（互斥） | 同（打开任一行：样式开关置灰、企业名全撤、圆点保留） |
| 标签淡入淡出 | 有（150ms） | 有（150ms，v0.7.3 同款） |
| 路名 | z≥17 出现 | **比例尺 300m 段即出**（Web 版放宽，洲哥指示；App 不动） |
| 影像注记 | 无入口 | 浮层第 6 行「影像注记」（P3 补齐） |
| 台账 Excel 更新 | — | 浮层末行「导入台账 Excel」（P3） |

## 台账 Excel 导入（P3）

浮层点「导入台账 Excel」→ 选《边合区企业台账.xlsx》→ 内存立即生效
（状态栏显示 164 条 / 可上图 154 等统计），解析规则与 `.rebuild_seed_v7.py`
逐条对齐（id=td-行号、坐标校验、仅简称、同点位重复只提示不合并）。

**持久化**：导入成功后点状态栏里的「下载数据文件」，把下载的 `data.js`
替换 `Web版/data/data.js` 即完成持久更新（浏览器无权直接写盘，这是等价做法）。

## 更新数据（脚本方式，App 同源）

1. 更新 `BhqMap/app/src/main/assets/` 下的 `sample_enterprises.json` / `roads.kml` / `parcels.kml` / `idle_factories.json`；
2. 在工程根目录跑 `python .gen_web_data.py`（自带 13/13/25/164 断言）；
3. 刷新页面。

## 测试

```
node test/run.js                 # 无头冒烟 17 项（P1/P2/P3），改引擎后必跑
node test/browser.verify.js      # 真实浏览器走查：路名出现/消失/无残留（需 headless chromium）
node test/browser.verify.p3.js   # 真实浏览器走查：cia/Excel 导入/下载/淡入淡出
```
