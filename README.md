# 边合区产业地图（BhqMap）

面向边境经济合作区的企业分布地图工具：天地图卫星影像底图，企业点位按身份分级显示，配套闲置地块、闲置厂房、园区路网图层，并同步提供功能对齐的 Web 版。服务园区企业管理、招商洽谈与日常巡查场景。

## 功能特性

- **卫星底图**：天地图 WMTS 影像（WGS-84 坐标系直配，免转换）
- **企业点位**：164 条台账（可上图 154 家），按身份分级显示（规上企业 / 重点企业 / 协作区项目 / 园区项目 / 行政事业单位），专属颜色与字号，防重叠标签避让引擎
- **专题图层**：闲置地块（紫框）、闲置厂房（橙块）三态互斥；园区路网道路名按比例尺显隐
- **台账导入**（v0.8.0）：手机上直接选择 .xlsx 导入企业台账与闲置厂房，导入前统计确认，数据持久保存
- **软件内更新**（v0.9.0）：启动时自动检查新版本，点一下即下载安装；台账数据变更走静默热更新，不必再发版
- **更新提示红点**（v0.9.1）：有新版本时右下角版本号旁亮红点，跨重启保留；版权页按钮同时显示「有新版本 vX 可用」
- **详情面板**：企业档案三段式面板，名称 / 类型 / 主营业务固定，简介滚动（v0.8.1 起 96 家主营、102 条简介）
- **版权信息页**：权益方、开发团队、审图号（GS(2025)1508号）

```

├── BhqMap/                              # Android 工程源码（Kotlin + osmdroid + 天地图 WMTS）

├── 边合区企业台账.xlsx                    # 台账数据源模板（B/C/D/E 列为全称/简称/经度/纬度）
└── 边合区产业地图-Android应用方案-v1.0.md   # 立项方案
```

## 构建

1. Android Studio 打开 `BhqMap` 目录
2. 在 `BhqMap/local.properties` 配置（不进 Git，需自行准备）：
   - `sdk.dir`：本机 Android SDK 路径
   - `TIANDITU_TK`：天地图开发者令牌（[官网](https://console.tianditu.gov.cn/api/key) 免费申请）
   - `KEY_ALIAS` / `KS_PASS` / `KEY_PASS`：签名密钥参数（搭配自备的 keystore）
3. Build → Generate Signed APK
